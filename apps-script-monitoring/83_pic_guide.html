    Otomatis vs tugas PIC

    Otomatis

      PIC

        Checklist sebelum selesai

        • Pastikan tanggal, PIC, dan DAY TYPE benar.
        • Periksa hasil automation dan Notes.
        • Jalankan Airflow pada semua window aktif.
        • Isi Start Time, End Time, status, dan evidence manual.
        • Review lalu Copy Summary sebelum dikirim.
        Apa yang berubah di daily file?
        Arti status monitoring
        OKProses selesai sesuai hasil.
        RUNNINGProses masih berjalan.
        FAILEDPerlu cek Notes/evidence.
        NO SCHEDULETidak dijadwalkan pada tanggal target.
        NOT FOUNDRun atau file belum ditemukan.
        SKIPPEDTidak berlaku untuk jenis hari tersebut.
        Jika ada masalah
        • Daily file belum ada: gunakan Create Daily atau hubungi admin.
        • PIC/day type salah: jangan ubah formula; cek Schedule dan Holiday.
        • Window Airflow tidak muncul: pastikan profil hari yang aktif benar.
        • Daily file sudah ada: sistem tidak menimpa input dan mengembalikan ALREADY_EXISTS.
        • Ada popup Holiday: daily file existing tidak berubah otomatis; eskalasi ke admin.
        Catatan untuk admin
        Generate Schedule setelah perubahan roster, Validate Template sebelum aktivasi, dan Setup All Triggers hanya dari akun owner automation. Hindari trigger time-based dengan beberapa owner.
